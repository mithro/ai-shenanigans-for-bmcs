1. QEMU emulation

The faithful AST2050 model is the QEMU machine kgpe-d16-bmc in the mithro/qemu fork, branch claude/bmc-functionality (submodule at asus-kgpe-d16-firmware/qemu-firmware/qemu/qemu, pinned to afb611e129). The AST2050 is not supported by upstream QEMU (earliest Aspeed SoC is the AST2400/G4); the G3 SoC class (aspeed_soc_ast2050, silicon-rev 0x00000202) was built by specializing the AST2400 code with G3-faithful differences, validated against the AST2050 datasheet and real-silicon reads. The per-peripheral model program was integrated via PR #25; its integration suite reached 108 passed / 0 xfailed on 2026-07-13, with further tests added since (e.g. the H-PLL rate test).

1.1 Firmware boot oracles (all pass in CI)

The governing principle: the legacy/proprietary firmware is the faithfulness oracle and must always keep booting — a change that breaks a legacy boot is a model bug, never a firmware bug.
