Signals exercised (soc §11 power seq):
  GPIOA4  ASUS_BMC_CTL_LOCKOUT_N  out  HIGH = "BMC in control" (reclaimed from PHYLINK alt-fn)
  GPIOB1  CTL_REQ_POWERUP_N       out  active-low power-up request
  GPIOF0  CTL_REQ_POWERDOWN_N     out  active-low force-off request
  GPIOH2  STA_LINE_POWER          in   1 = host powered, 0 = off (feedback)

PASS gate: GPIOH2 observed 0 (off) -> 1 (after power-ON request) -> 0 (after force-OFF request) —
i.e. the Zephyr GPIO driver both DRIVES the power-request outputs and READS the resulting power-
state feedback, and the QEMU pwrseq latch tracks it.
