Why this is a VIC+Timer proof: k_msleep() sleeps the thread and only returns when a system-timer
tick IRQ (Timer1, VIC source 16) fires and the kernel tick handler wakes it; k_uptime_get() is
derived from the same tick count. So N successful k_msleep()+uptime iterations = N proofs the timer
FIRES, the VIC ROUTES + ACKS its IRQ, and the ISR path works. A dead timer/VIC hangs the 1st sleep.
