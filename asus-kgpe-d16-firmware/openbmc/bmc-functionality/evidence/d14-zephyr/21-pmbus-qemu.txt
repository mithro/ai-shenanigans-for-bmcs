PMBus registers read (each = SMBus write-command + repeated-START + read, via i2c_write_read):
  VOUT_MODE (0x20)   read-byte -> 0x17  (linear mode, 5-bit signed exponent = -9)
  READ_VOUT (0x8B)   read-word -> 0x1800 ULINEAR16 mantissa; value = 0x1800 * 2^-9 = 6144/512 = 12.000 V
  PMBUS_REVISION (0x98) read-byte -> 0x22 (PMBus 1.2)
The sample sign-extends the VOUT_MODE exponent and decodes READ_VOUT to millivolts, then PASSes if the
+12 V rail is in the 11.5-12.5 V window.

6144/512 = 12.000 V = 12000 mV (matches PSU_VOUT_VOLTS=12); REVISION=0x22 (PMBus 1.2). All three reads
match the model bit-for-bit.

RESULT: PASS in QEMU. The Zephyr port drives PMBus over the G3 I2C master on a THIRD distinct engine
(engine 0 = I2C1; the sensor smokes used engines 1/3/4), reading the PSU's mode + main-rail voltage +
revision. Row 24 (PSU PMBus): ZQ ⬜→✅.
