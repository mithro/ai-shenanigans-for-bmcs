===== THE KEY FAITHFULNESS FINDING (hardware "weirdness" was MY code) =====
First attempt FAILED: both the pre-select AND post-select SPD reads NAKed (err -6). Rather than blame
the model, I read hw/i2c/kgpe_d16_i2c_fabric.c: the fabric's match() returns "not reachable" whenever
SYS_PWRGD is LOW — "QU9 open: the whole fabric is electrically disconnected". SYS_PWRGD ← the GPIO
"kgpe-host-on" latch, which is OFF at boot. So the DIMM SPD/TSOD bus is UNREACHABLE while the host is
off — a REAL hardware constraint (the DIMM rails, and thus the SPD, are only powered with the host on),
not a bug. FIX (proper, not a workaround): power the host ON first, then the fabric (QU9) closes and
U23 hands the BMC ownership of the QU5 selects (sb_post_complt_n low). This is exactly how a real BMC
would reach the SPD outside the host's POST window.

Sequence the Zephyr port performs:
  1. reclaim GPIOA4 from its PHYLINK alt-fn (SCU unlock + clear SCU74[25]); A4 high = BMC in control.
  2. power the host ON (pulse reset#/power-up# low→high on GPIOB6/B1) → STA_LINE_POWER (GPIOH2) = 1.
  3. drive the QU5 selects to Y2 (DIMM A-D): S0=0 (GPIOF4/gpio1-p12 low), S1=1 (GPIOF5/gpio1-p13 high).
  4. read the SPD at 0x51 on i2c1 (SMBus write-offset + read-byte).
  5. restore: force the host back OFF (GPIOF0 pulse), leaving the board as found.
