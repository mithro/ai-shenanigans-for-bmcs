DEVICE-MATRIX row 9 (USB virtual media) / #182 — virtual media as a CD-ROM: QEMU PASS
===================================================================================

The USB virtual-media mass_storage gadget now sets lun.0/cdrom=1 (SCSI type 5,
read-only), so it presents as a CD-ROM (§9 'virtual keyboard/mouse/CD') instead of a
removable Direct-Access disk. Validated in QEMU via the f6usb gate (dummy_hcd loopback).
The host-side /dev/sr0 node needs usb-storage+sr_mod on the host (not loaded by the
minimal-initramfs loopback) -> that host-side CD-ROM view is the USB/IP-to-a-real-host
silicon path (row 9 LS 🔷), same transport that proved the disk variant on silicon.
