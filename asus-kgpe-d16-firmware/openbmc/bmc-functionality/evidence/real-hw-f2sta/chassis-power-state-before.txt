--- B. The STATE-IN line is CORRECT — GPIOH2 physically tracks host power ---
devmem 0x1E780020  = 0xF403FFFF   # GPIO20 (bank E-H data). H2 = bit26 = 1 => HIGH
devmem 0x1E780024  = 0x0301000E   # GPIO24 (bank E-H dir).  H2 = bit26 = 0 => INPUT
devmem 0x1E6E2074  = 0x4204D000   # SCU74 (multi-fn pin ctl; bit14 = SDA7/GPIO mux)
  => GPIOH2 (STA_LINE_POWER, ball A12) reads 1 with the host ON, active-high (1=on),
     exactly matching Raptor's board map, the DTS `power-state-in` line name, and the
     QEMU model (GPIO20 bit26, 1=on). The DTS line index + polarity are RIGHT.
